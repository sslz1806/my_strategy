# 涨跌停情绪因子简化教学 Notebook 设计

## 1. 目标

新建一个简单、可读、可重复运行的日频教学 Notebook，用于回答两个问题：

1. 五个涨跌停情绪因子与未来市场收益是否存在方向一致的关系？
2. 按各因子自身方向生成持仓信号后，信号触发与未触发期间的未来收益有何差异，空仓平均规避了多少市场收益？

Notebook 不复现原研究中的周度组合模型，不使用 15 分钟打板近似，不加入趋势增强、宽基稳健性或真实资金回测。原文件 `reproduce_sentiment_timing.ipynb` 保持不变，新增文件为：

`因子回测/涨跌停情绪因子/simple_sentiment_timing.ipynb`

## 2. 研究参数

参数集中放在 Notebook 开头，默认值如下：

```python
FACTOR_WINDOW = 5
FORWARD_DAYS = [1, 3, 5, 10, 20]
SIGNAL_LOOKBACK = 252
SIGNAL_QUANTILE = 0.70
MIN_HISTORY = 60
```

- `FACTOR_WINDOW` 控制因子使用最近多少个交易日，可直接修改为 3、5 或 20。
- `FORWARD_DAYS` 控制检验信号形成后未来多少个交易日的累计收益。
- `SIGNAL_LOOKBACK` 控制动态信号阈值使用的历史窗口。
- `SIGNAL_QUANTILE` 控制看多信号的高、低分位边界。
- `MIN_HISTORY` 控制生成阈值前至少需要多少条历史观测。

研究日期、数据源和输出路径也放在同一参数单元。数据读取日期应早于正式统计起点，为因子窗口和信号阈值提供预热数据。

## 3. 因子定义与方向

研究只保留五个可由日线数据确定的因子：

| 因子 | 计算口径 | 看多方向 |
|---|---|---|
| 涨停占比 | 窗口内涨停总数 ÷ 窗口内有效股票总数 | 高 |
| 跌停占比 | 窗口内跌停总数 ÷ 窗口内有效股票总数 | 低 |
| 净涨停占比 | 涨停占比－跌停占比 | 高 |
| 昨日涨停股今日收益 | 窗口内昨日涨停事件对应的今日收益加权平均 | 高 |
| 昨日跌停股今日收益 | 窗口内昨日跌停事件对应的今日收益加权平均 | 高 |

股票池沿用现有研究口径：沪深 A 股代码首位为 6、0、3，并剔除 ST、停牌、无有效涨跌停价格或必要行情字段无效的记录。

两个事件收益因子按窗口内全部有效事件加权平均。没有事件的窗口保持为空，不使用零值或前值填充，因为“没有事件”不等同于“事件收益为零”。

## 4. 无未来函数的时间约定

交易日 `t` 的因子在 `t` 日收盘后形成：

- 当日涨跌停数量只使用 `t` 日及以前的数据。
- “昨日涨停股今日收益”和“昨日跌停股今日收益”在 `t` 日只使用 `t-1` 日事件及其在 `t` 日已经实现的收益。
- `t` 日动态分位数阈值只使用 `t-1` 及以前的因子值。实现中先对因子执行 `shift(1)`，再计算历史滚动分位数。
- `t` 日信号对应的未来 `h` 日收益为从 `t` 日收盘到 `t+h` 日收盘的市场累计收益。
- 代码中的负向位移只允许出现在未来收益标签构造中。未来收益不得参与因子、阈值或信号生成。

市场收益沿用现有 `build_market_forward_returns` 的全 A 正市值加权口径。该函数生成的未来收益只作为检验标签。

## 5. 信号规则

信号统一表示“允许持仓”的看多信号，但每个因子的比较方向不同：

- 高值看多因子：当前值不低于截至前一交易日的历史 `SIGNAL_QUANTILE` 分位数时触发。
- 跌停占比：当前值不高于截至前一交易日的历史 `1 - SIGNAL_QUANTILE` 分位数时触发。
- 历史有效样本少于 `MIN_HISTORY` 时，信号保持为空并排除出有效性统计。

方向是需要检验的经济假设，不是预设结论。若实际 IC、条件收益差或规避收益与预期方向相反，Notebook 必须如实展示。

## 6. 有效性与择时指标

每个因子、每个未来期限输出以下指标：

| 指标 | 定义 |
|---|---|
| 方向调整 Spearman IC | 原始 Spearman 相关乘以因子方向，使正值统一表示符合看多假设 |
| 有效样本数 | 因子、信号和未来收益均有效的观测数 |
| 触发次数 / 触发率 | 看多信号触发的数量及比例 |
| 触发后平均收益 | 信号为 1 时未来 `h` 日市场累计收益均值 |
| 未触发平均收益 | 信号为 0 时未来 `h` 日市场累计收益均值 |
| 筛选改善 | 触发后平均收益－未触发平均收益 |
| 平均规避收益 | `0－未触发平均收益`；正值表示空仓平均规避了下跌，负值表示平均错过上涨 |
| 触发后胜率 | 信号触发后未来累计收益大于零的比例 |
| HAC p 值 | 对二元信号与重叠未来收益的回归使用 HAC 稳健协方差 |

上述结果是条件收益研究。不同日期的多日持有区间可能重叠，因此不能把“触发后平均收益”直接解释为可复利的策略收益。

为补充实际择时效果，单独使用无重叠的一日执行口径：`t` 日收盘信号仅作用于 `t+1` 日市场收益。每个因子独立生成择时净值，与全 A 市值加权基准比较；不组合多个因子。

## 7. Notebook 结构

Notebook 控制在约八个短章节：

1. 研究目标与无未来函数时间线。
2. 参数、导入与项目路径。
3. 使用 `read_day_data` 简短加载日线数据，仅打印日期范围和数据量。
4. 用 Markdown 解释五个因子公式和方向，并调用封装函数计算因子。
5. 用 Markdown 解释历史分位数规则，并生成信号。
6. 展示连续因子和条件信号的有效性表格。
7. 绘制触发后平均收益热图、平均规避收益热图和单因子次日择时净值图。
8. 用 Markdown 说明结果读取方法、重叠收益限制和样本内研究限制。

不设置独立的数据质量章节，不输出大段调试信息。中文 Markdown 与代码注释重点解释业务口径、边界条件和防未来函数原因。

## 8. 代码复用与边界

扩展现有 `sentiment_timing_analysis.py`，加入日频因子、历史滚动分位信号和条件收益统计函数。Notebook 只保留研究参数、接口调用、少量结果整理和绘图，以保证教学主线清晰。

继续复用以下现有接口：

- `my_utils.fun.read_day_data`：加载日线数据。
- `sentiment_timing_analysis.build_market_forward_returns`：生成全 A 市值加权日收益和未来收益标签。
- 现有的必要字段校验和 A 股代码过滤逻辑。

新增函数应保持纯计算、输入输出明确，不读取隐藏的全局变量。原有周度函数和原 Notebook 行为保持兼容。

## 9. 边界处理

- 必要列缺失时给出明确报错。
- 输入为空或没有符合股票池条件的数据时停止计算。
- 没有昨日涨跌停事件时，对应事件收益为空，不填零、不前向填充。
- 历史阈值预热不足时信号为空，不强制设为 0。
- 样本尾部未来收益为空时，只从对应期限的统计中排除。
- 某因子只有单一取值、只有单侧信号或有效样本不足时，统计量返回空值并保留样本诊断字段。

## 10. 验证方案

1. 使用合成日线数据验证昨日事件与今日收益的日期对齐。
2. 对同一份历史数据分别执行“完整样本计算”和“截至某日截断计算”，确认截断日前的因子与信号完全一致，证明追加未来数据不会修改历史结果。
3. 验证动态阈值只读取移位后的历史因子序列。
4. 验证未来收益标签从信号日收盘后开始，且样本尾部按期限正确为空。
5. 使用项目指定的 `quant` Python 环境从头执行新 Notebook，并检查表格、图形和输出无报错。

若本地全量数据或外部环境使完整执行不可行，需明确记录失败位置、缺失条件和可复现的执行命令；静态结构验证不能替代完整执行结论。
