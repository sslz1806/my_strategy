## 主策略：涨停低开策略

完整实现于 `回测demo.ipynb`。

**策略流程：**

1. **选股信号**：筛选满足买入条件的股票，构成买入信号
2. **理论回测**：基于自定义trade函数构建买入卖出信号，对选股买入和交易卖出信号进行回测（记录买卖点，不涉及真实资金）
3. **风控信号**：生成资金仓位风控指令
4. **回测报告**：输出完整回测绩效
5. **实盘回测**：结合交易信号与风控信号，进行真实资金级别的模拟成交

**核心思想**：先定义买卖逻辑生成交易信号与风控信号，再基于信号执行实盘资金回测。

**策略逻辑：**

- **买入条件**：前一日涨停的股票，当日低开 -5% 到 -2.5% 之间
- **过滤条件**：使用MA7/EMA7/SMA7均线作为过滤器

## 开发约定

- **Python版本**：3.9+
- **数据处理库**：优先使用Polars，其次Pandas
- **数据存储**：本地Parquet文件（`E:\working\stock_data`）
- **编码风格**：遵循PEP 8
- **Notebook**：用于策略研究，生产代码用.py文件
- **日志文件**：必须放在对应文件夹的`log/`子目录中
