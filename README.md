# 策略项目简述

用于A股选股信号生成与回测的小型研究仓库，含信号筛选、交易撮合、风控和可视化示例。
已经做好的策略:涨停低开策略,在回测demo文件中可以看到策略的思想。

#### 主要文件

- `my_utils/` - 核心接口函数包（所有工具函数已打包至此）
  - `fun.py` - 本地数据接口(polars)、特征计算函数
  - `trade_fun.py` - 理论回测框架交易函数、风控函数
  - `stock_api.py` - 股票数据源接口(tushare,掘金等)
  - `mapping.py` - 数据清洗与转换函数
  - `my_qmt.py` - QMT实盘交易接口
  - `stock_plot.py` - 数据可视化接口
  - `email_fun.py` - 邮件通知
  - `pd_fun.py` / `stock_db.py` - 辅助函数
- `log/` - 日志目录
- `回测demo.ipynb` - 完整策略:涨停低开策略回测流程代码

- `my_backtester/` - 实盘回测框架,将买卖信号传入,然后按照真实资金进行成交回测
- `任务/` - 1.数据更新任务 2.QMT实盘交易任务,包括买卖
- `信号交割复盘/` - 交割单html文件,用于可视化复盘策略信号的好坏
- `因子回测/` - 因子研究（完善中）
- `信号文件/` - 信号csv文件
